EASY INSTALL

Install CleanMac from releases

Download the latest packaged macOS build from GitHub Releases and start reclaiming disk space in seconds.

Go to Releases
github.com/abzgif/mac-cleaner/releases
1. Download the latest release

Open the GitHub Releases page and download the latest CleanMac archive or disk image.

2. Move to Applications

Extract the archive if needed, then drag CleanMac.app into your Applications folder.

3. Grant file access when prompted

Allow folder or Full Disk Access when scanning system caches, app leftovers, or developer directories.

Gatekeeper warning

If macOS warns that the app is unsigned on first launch, click Done, then open System Settings > Privacy & Security and choose Open Anyway.
